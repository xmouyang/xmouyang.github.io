**Course Description**: This course introduces the fundamental principles and protocols of computer networking using a top-down approach. Topics include network architectures, application-layer protocols, transport protocols, reliable data transfer, congestion control, the network data and control planes, routing, IP addressing, IPv6, and link-layer/local-area-network technologies. The course also includes practical protocol analysis using Wireshark.

**Course Objectives**: After completion of this course, students should understand how modern computer networks are organized across protocol layers, how major Internet protocols operate, and how design choices at the application, transport, network, and link layers affect reliability, efficiency, scalability, and performance. Students will also write simple client-server applications using socket programming.
