COMP5621: Computer Networks (Fall 2026)

Computer Science and Engineering, Hong Kong University of Science and Technology

How does the Internet work? How do network protocols provide reliable, efficient, and scalable communication across applications, hosts, routers, and local networks?

Instructor: Prof. Xiaomin Ouyang
Class Time: Wednesday/Friday 3:00PM - 4:20PM (Rm 2464, Lift 25-26)
Email: xmouyang@cse.ust.hk
Office Hour: Ask questions after the lecture, or by appointment via email. Teaching Assistants: Mr. Runxi Huang (rhuangbj@connect.ust.hk), Mr. Haoxian Liu (hliueu@connect.ust.hk), and Mr. Longxiang Tang (ltangap@connect.ust.hk)

Communication and Announcement: Canvas will be used for course materials and announcements.

Course Description: This course introduces the fundamental principles and protocols of computer networking using a top-down approach. Topics include network architectures, application-layer protocols, transport protocols, reliable data transfer, congestion control, the network data and control planes, routing, IP addressing, IPv6, and link-layer/local-area-network technologies. The course also includes practical protocol analysis using Wireshark.

Course Objectives: Understand the basic terminologies, principles, and protocols in computer networks; Write simple server-client applications using Socket Programming.
